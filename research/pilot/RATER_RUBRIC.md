# Gold-Sample Labeling Rubric (G1 + G2)

For the independent rater(s). You will see short podcast transcript excerpts
with speakers marked HOST and GUEST. No show names, dates, or real names —
that's deliberate; please don't try to guess or look up who is speaking.
There are no right-answer quotas: some batches may have many "yes" answers,
some almost none.

**Ground rule:** label only what is on the page. Don't infer what the host
"probably meant" — if the text doesn't show it, the answer is No. When
genuinely torn after rereading twice, use the UNSURE option (it exists so
you never have to force a coin flip). Please don't discuss items or answers
with anyone (including the PI) until the whole batch is submitted.

## Part 1 — "Is this a disagreement episode?" (300 items, ~1 min each)

You'll read a window of conversation. Answer ONE question:

> Does the GUEST state a position/judgment, and does the HOST then express
> a different position on the SAME issue — even partially, even politely?

- **YES** — host pushes back, in any style: "I see it differently…",
  "That's fair, but…", "Hmm, is that really true though?"
- **NO — no stance conflict**: pure Q&A, agreement, topic change, the host
  merely summarizing the guest's view, or backchannels ("right", "mm-hmm").
- **NO — excluded type**: the conflict is about a checkable fact/trivia
  ("it was 1987, not 1989"), not judgment; or the exchange is a scripted
  debate-show segment.
- **UNSURE**

Devil's-advocate questions count as YES only if the host frames a contrary
position as their own or presses it repeatedly; a single "playing devil's
advocate here…" question is NO.

## Part 2 — labeling host turns inside disagreements (200 items, ~1-2 min each)

You'll see one HOST turn (with a little context above it). Four yes/no
questions per turn:

1. **Concessive opener:** does the turn OPEN by validating/agreeing before
   disagreeing? ("That's a great point, and…", "I hear you, but…",
   "Totally fair — though…"). The validation must come FIRST, before any
   pushback. Agreement in the middle or end of the turn = No.
2. **Both-sides framing:** does the turn end up refusing to pick a side?
   ("there's merit on both sides", "it depends how you look at it" AS the
   turn's conclusion). Presenting both views and then picking one = No.
3. **Bald contradiction:** does the turn contain a flat, unsoftened
   contradiction? ("No.", "I disagree.", "That's just wrong.") — with no
   softener in the same sentence ("I disagree, though I see why…" = No).
4. **Hedges:** tick every hedge phrase you see in the turn from the
   checklist provided on the sheet ("I think", "maybe", "sort of",
   "kind of", "perhaps", "it could be argued", "to some extent",
   "arguably", "in some ways").

## Practicalities

- Budget: ~6-8 hours total. Split freely across days; there's a progress
  save on the sheet. Random order is intentional — don't reorder.
- First 30 items are calibration: the PI will review those with you against
  this rubric (they don't count toward the final sample), then you work
  alone.
- If an excerpt is garbled/unreadable (transcription errors), mark UNSURE
  and flag it — don't try to reconstruct it.

_(Sheet generator and item selection: built after Stage-1 screening runs on
the pilot corpus; items will be stratified and randomized automatically.)_
